# Orders of the Day

Time-block app for João's weekly routine: what to do right now with a countdown and checklist, today's timeline, and this month's recurring chores.

Live at https://jpvanacor.github.io/orders-of-the-day/

Every change is a commit, so any earlier version can be restored from the history. GitHub Pages publishes the `main` branch about a minute after each push. On the phone, close the app completely and open it again to load the new version.
